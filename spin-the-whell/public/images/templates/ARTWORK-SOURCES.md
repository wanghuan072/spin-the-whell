# Template artwork sources

Downloaded on 2026-08-12 and converted to local WebP assets for predictable loading.

- Country flags: FlagCDN / Flagpedia, based on Wikimedia Commons flag files — https://flagcdn.com/
- Pokémon sprites: PokéAPI sprite repository — https://github.com/PokeAPI/sprites
- NBA team logos and player headshots: NBA official CDN — https://cdn.nba.com/
- Game genre, movie genre, and elemental type backgrounds: original no-text scene sheets generated for this project with OpenAI image generation on 2026-08-12; split into one local WebP background per wheel entry by `scripts/prepare-wheel-slice-backgrounds.mjs`.
- Pokémon stage: Pokémon Legends: Z-A screenshot distributed on the game product listing — https://www.instant-gaming.com/en/16028-buy-pokemon-legends-z-a-switch-nintendo-eshop/
- Event stage: `Findings Festival 2018.jpg`, ItsLedeux, CC BY-SA 4.0 — https://commons.wikimedia.org/wiki/File:Findings_Festival_2018.jpg
- Yes/No stage: `East Lothian Landscape, I went down to the crossroads`, Richard West, CC BY-SA 2.0 — https://commons.wikimedia.org/wiki/File:East_Lothian_Landscape_,_I_went_down_to_the_crossroads_-_geograph.org.uk_-_7789915.jpg
- Europe stage: `Europe satellite orthographic.jpg`, public domain — https://commons.wikimedia.org/wiki/File:Europe_satellite_orthographic.jpg
- Color stage: `A palette with a spatula and paint brushes.jpg`, public domain — https://commons.wikimedia.org/wiki/File:A_palette_with_a_spatula_and_paint_brushes.jpg
- Basketball stage: `AIS Arena interior, January 2026 01.jpg`, DaHuzyBru, CC BY-SA 4.0 — https://commons.wikimedia.org/wiki/File:AIS_Arena_interior,_January_2026_01.jpg
- Games stage: `Game Controllers.jpg`, Ted Mielczarek, CC0 — https://commons.wikimedia.org/wiki/File:Game_Controllers.jpg
- Movies stage: `Movie theater seats (Unsplash).jpg`, Elijah Flores, CC0 — https://commons.wikimedia.org/wiki/File:Movie_theater_seats_(Unsplash).jpg
- World stage: `Antique World Map of Continents and Oceans 1700 (cropped).png`, public domain — https://commons.wikimedia.org/wiki/File:Antique_World_Map_of_Continents_and_Oceans_1700_(cropped).png
